## Make a request {#first-request}

Create a client with your API key, and ask for a parcel by its tracking
number.

```js title="track.js"
import { ParcelClient } from '@example/parcel-client';

const client = new ParcelClient({ apiKey: process.env.PARCEL_API_KEY });

const parcel = await client.track('PX-2041-7788');
console.log(parcel.status, parcel.estimatedDelivery);
```

```text title="Output"
in_transit 2026-10-12
```

:::tip

Keep the key in an environment variable, as above, and out of the code you
commit.

:::

## What comes back {#response}

| Field | Type | Meaning |
| --- | --- | --- |
| `status` | string | `created`, `in_transit`, `delivered` or `returned` |
| `estimatedDelivery` | date | Absent once the parcel is delivered |
| `events` | array | Every scan of the parcel, newest first |
| `weight` | number | In grams |

<details>
  <summary>The full response, as JSON</summary>


</details>

## Handle errors {#errors}

Every method throws a `ParcelError` with a `code` you can switch on.

<Tabs>
  <TabItem value="async" label="async / await">

    ```js
    try {
      await client.track('nope');
    } catch (err) {
      if (err.code === 'not_found') {
        console.log('No such parcel');
      } else {
        throw err;
      }
    }
    ```

  </TabItem>
  <TabItem value="then" label="Promises">

    ```js
    client.track('nope').catch((err) => {
      if (err.code !== 'not_found') throw err;
      console.log('No such parcel');
    });
    ```

  </TabItem>
</Tabs>

| Code | When | Retry? |
| --- | --- | :---: |
| `not_found` | No parcel has this tracking number | no |
| `unauthorized` | The key is missing or wrong | no |
| `rate_limited` | More than 100 requests in a minute | after a pause |
| `unavailable` | The service is down | yes |

:::warning[Rate limits]

The limit is per key, not per machine. Two services sharing a key share its
limit.

:::

:::danger

Never put the API key in code that runs in a browser. Anyone who opens the
page can read it.

:::
