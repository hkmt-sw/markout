# sRGB color profile

`sRGB-v2-magic.icc` is the ICC profile a PDF/A file names as its output
intent (see `pdf_pdfa.go`): the colors markout draws are DeviceRGB, which
PDF/A reads as sRGB. It is embedded as it is, not changed.
